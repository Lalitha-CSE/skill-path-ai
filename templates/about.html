About Skill Path AI

Purpose

Skill Path AI is an AI/ML student learning companion and knowledge-based question-answering agent. Its tagline is “Learn. Build. Grow.” Students can ask questions about Python, Artificial Intelligence, Machine Learning, Data Science, AI projects, interview preparation, internships, GitHub, and career roadmaps.

The agent searches its local knowledge base, identifies the most relevant note, calculates a matching score, shows the source note, and provides an answer based on that source. Everything runs locally — no API key or internet connection is required after dependencies are installed.

How the Knowledge Agent Works

Skill Path AI uses a Find → Check → Answer workflow:

  1. Find: The student's question is converted into a TF-IDF vector and compared against every note in the knowledge base.
  2. Check: Cosine similarity measures how closely the question matches each note. The best match is selected and its score is compared against a configurable threshold.
  3. Answer: If the score meets the threshold, the note's text is returned as the answer along with its source and score. Otherwise, a safe fallback message is shown instead of presenting an unrelated note.

TF-IDF and Cosine Similarity

TF-IDF (Term Frequency–Inverse Document Frequency) converts text into numbers by weighing how important a word is to a note relative to the whole knowledge base. Common words like “the” receive low weight; topic-specific words receive higher weight.

Cosine similarity measures the angle between the question vector and each note vector. A value of 1 means identical direction (very similar content); 0 means no shared meaningful terms. The result is a similarity score between 0 and 1, shown as a percentage. This score estimates relevance, not factual correctness.

Current Limitations

  • Answers are limited to the starter knowledge base in data/knowledge.json.
  • The similarity score measures textual relevance, not factual correctness. Always verify answers for coursework.
  • Some notes are marked as drafts; these carry a warning.
  • Roadmaps and career guidance are general suggestions, not personalized plans based on user data, and do not guarantee jobs, salaries, or outcomes.
  • No external AI model or paid API is used; results depend on the quality and coverage of the local notes.

Technology Stack

  • Frontend: HTML5, CSS3, JavaScript
  • Backend: Python with Flask
  • Templates: Jinja2
  • Knowledge storage: JSON files
  • Retrieval: scikit-learn TF-IDF and cosine similarity
  • Testing: Python unittest
